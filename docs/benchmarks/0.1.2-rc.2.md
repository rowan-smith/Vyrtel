# Benchmarks: 0.1.2-rc.2

Measured on 2026-11-11 on the OneProvider host, following the [benchmark method](../benchmark-method.md). See the [overview](../benchmarks.md) for the comparison between versions. Anything not measured is marked as not run.

These results come from the runs made while 0.1.2-rc.2 was prepared, not from a run of the published release asset; each section names the build it measured:

- **Published artifacts:** the published release asset and image, checked after the release.
- **Local baseline:** `1332e29`, whose code is exactly the tag's, built as the release workflow builds it (`rust:1-bookworm`, baseline x86-64 CFLAGS). Five runs, against 0.1.1 measured again in the same session.
- **Smoke tests and same-host transport:** `bd25064`, which differs from the tag only in checking one password at a time (`crates/server/src/auth.rs`, `routes/session.rs`). The transport load does not sign in.

- **Vyrtel:** 0.1.2-rc.2
- **Baseline duration:** 2.8 min for 5 run(s) (33 s, 33 s, 34 s, 33 s, 33 s)
- **Workload:** seed 42; 100,000 log events, 1,000 traces, 100 metric points in batches of 500; each query once cold then 20× warm; mixed load 20s (3s warmup discarded) with 4 workers
