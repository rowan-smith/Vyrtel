# Benchmarks: 0.1.2-rc.1

Measured on 2026-11-10 on the OneProvider host, following the [benchmark method](../benchmark-method.md). See the [overview](../benchmarks.md) for the comparison between versions. Anything not measured is marked as not run.

- **Vyrtel:** 0.1.2-rc.1
- **Baseline duration:** 2.8 min for 5 run(s) (33 s, 33 s, 33 s, 33 s, 33 s)
- **Workload:** seed 42; 100,000 log events, 1,000 traces, 100 metric points in batches of 500; each query once cold then 20× warm; mixed load 20s (3s warmup discarded) with 4 workers
- **Binary:** the `vyrtel` binary inside the published image `ghcr.io/rowan-smith/vyrtel@sha256:5a60c431d46aca5a…`. The release asset `vyrtel-linux-x86_64` does not start on this CPU: it exits with `SIGILL` on an AVX2 instruction and needs glibc 2.38 (fixed in 0.1.2-rc.2).
- **Transport:** built from source at the tag in `rust:1.96-bookworm`.
