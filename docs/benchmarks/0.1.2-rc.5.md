# Benchmarks: 0.1.2-rc.5

Measured on 2026-11-15 on the OneProvider host, following the [benchmark method](../benchmark-method.md): post-release verification of the published prerelease. See the [overview](../benchmarks.md) for the comparison between versions. Anything not measured is marked as not run. The transport regression comparison was run on 2026-11-18, on the same host.

- **Vyrtel:** 0.1.2-rc.5
- **Baseline duration:** 2.7 min for 5 run(s) (33 s, 33 s, 33 s, 33 s, 33 s)
- **Workload:** seed 42; 100,000 log events, 1,000 traces, 100 metric points in batches of 500; each query once cold then 20× warm; mixed load 20s (3s warmup discarded) with 4 workers
- **Binary:** the published release asset `vyrtel-linux-x86_64`, verified against `SHA256SUMS`; smoke tests on the published image.
- **Previous release:** 0.1.1, measured again in the same session with the same harness and configuration.
- **Transport:** built from source at the tag in `rust:1.96-bookworm`.

Byte sizes in the tables below are binary: 1 MiB is 1,048,576 bytes. The harness that produced them labelled them KB, MB and GB.
