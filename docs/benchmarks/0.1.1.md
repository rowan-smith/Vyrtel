# Benchmarks: 0.1.1

Measured on 2026-11-10 on the OneProvider host, following the [benchmark method](../benchmark-method.md). See the [overview](../benchmarks.md) for the comparison between versions. Anything not measured is marked as not run.

- **Vyrtel:** 0.1.1
- **Baseline duration:** 2.6 min for 5 run(s) (31 s, 31 s, 32 s, 31 s, 32 s)
- **Workload:** seed 42; 100,000 log events, 1,000 traces, 100 metric points in batches of 500; each query once cold then 20× warm; mixed load 20s (3s warmup discarded) with 4 workers
- **Binary:** the published v0.1.1 release asset `vyrtel-linux-x86_64`, verified against `SHA256SUMS`.
- **Role:** measured as the previous release for 0.1.2-rc.1, in the same session, with the same harness and configuration.
