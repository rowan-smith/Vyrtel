## How to sign

Open a pull request. The CLA bot will ask you to sign by posting this comment on the pull request:

> I have read the CLA Document and I hereby sign the CLA

Your GitHub username, the pull request and the time of signing are recorded. You only need to sign
once; the signature covers all of your future Contributions under this version of the Agreement.
